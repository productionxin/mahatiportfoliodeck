# Client — Mahati Bhikshu

Portfolio site for **Mahati Bhikshu** — Kuchipudi dancer, film actor, choreographer and educator.

> One life. Many stages.

Built and maintained by [Production X Creative](https://productionx.in).

## Site sections

`about` · `works` · `film` · `teaching` · `events` · `press` · `gallery` · `contact`

## Stack

- [TanStack Start](https://tanstack.com/start) (React 19, file-based routing via `src/routes/`)
- Vite + TypeScript
- Tailwind CSS + shadcn/ui (Radix primitives)
- Deployed on Vercel (`vercel.json`)

## Develop

```
bun install
bun dev       # vite dev
bun build     # vite build
bun lint      # eslint
```

Routing conventions are documented in [`src/routes/README.md`](src/routes/README.md).
